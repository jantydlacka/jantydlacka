Backend developer, mostly in PHP. I design and build internal systems, APIs and integrations with external services – e-signatures, BankID, payment
gateways, Czech government registries. Day to day I work with PHP 8, Nette, Doctrine, MySQL, Docker, GitLab CI.

The repositories below are small, documented portfolio projects – each README explains
what it does and why it is built that way.

## PHP

- **[cms-lite-nette](https://github.com/jantydlacka/cms-lite-nette)** – multilingual-ready CMS in
  Nette 3.3: pages, news, Markdown components; ports & adapters, PHPStan max, Playwright end-to-end tests.
- **[symfony-cms](https://github.com/jantydlacka/symfony-cms)** – CMS on Symfony 8.1, PHP 8.4 and
  PostgreSQL 18, following Symfony best practices.
- **[laravel-shop](https://github.com/jantydlacka/laravel-shop)** – small e-shop in Laravel 13,
  Livewire and Filament: guest checkout, stock locking, admin order workflow.

## TypeScript

- **[node-shop](https://github.com/jantydlacka/node-shop)** – the laravel-shop JSON API reimplemented
  in Node.js (Fastify, Kysely, MySQL), with measured parity against the Laravel version.
- **[shop-react](https://github.com/jantydlacka/shop-react)** – React storefront for that API
  ([live demo](https://jantydlacka.github.io/shop-react/)).

## AI and tools

- **[mdbrowse](https://github.com/jantydlacka/mdbrowse)** – read-only Markdown viewer for Linux,
